# Animated F1 profile

Upload README.md, STATIC.md, and the entire assets folder at the root of your public profile repository. All animation files are local GIFs; no API keys or hosted badge services are needed.

The README includes an animated introduction, driver briefing, twelve individually linked technology cards, three linked project cards, a career timeline, an audio equalizer, and a contact panel. Links and expandable details provide GitHub-native interaction. GIFs loop automatically; there are no JavaScript widgets or hover effects.

STATIC.md is a motion-free edition with PNG equivalents and the same links. All facts remain available in readable text or image descriptions. Motion and equalizers are decorative, not activity metrics or proficiency scores.

Technology choices were checked against public repository files: personal-portfolio/src/data/skills.ts, personal-portfolio/package.json, Campus_Reconnect/package.json, and qrgpt/package.json. Python and biographical details came from the supplied profile PDF.

Technology logo shapes are from Simple Icons (https://github.com/simple-icons/simple-icons), distributed under CC0. Brand names and marks belong to their respective owners. See assets/garage/ATTRIBUTION.md.
